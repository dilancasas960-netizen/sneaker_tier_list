# 👟 Sneaker Tier List

Aplicación web interactiva desarrollada para realizar una encuesta de popularidad de 20 modelos icónicos de zapatos deportivos y urbanos, clasificándolos automáticamente en un ranking global con formato de *tier list*.

## 🚀 Tecnologías utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** PHP 8+
- **Base de Datos:** MySQL
- **Entorno Local:** XAMPP (Apache / phpMyAdmin)
- **Conectividad:** PHP PDO con consultas preparadas

---

## 📋 Requisitos previos

Para ejecutar este proyecto en tu equipo local necesitas tener instalado:
- **XAMPP** (o cualquier entorno local con soporte para PHP y MySQL).
